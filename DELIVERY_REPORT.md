# Chess Vision Trainer — результат версии расширения 1.1

## Готовые приложения

Основная копия находится на рабочем столе, в папке Chess Vision Trainer. Веб-тренажёр запускается через Start Chess Vision.cmd. Расширение Chrome/Chromium/Edge загружается из вложенной папки Chess Vision Extension; оно работает самостоятельно в браузере. Исходники и история Git сохранены в M1rshy/chess-tracker, старый ZIP — в отдельной ветке и original-backup.

## Что работает

Веб-тренажёр: легальные шахматы, история, отмена/повтор, FEN/PGN, Stockfish 17.1 WASM depth 15 / MultiPV 1, оценки и мат, PV, стрелки, шкала, темы, компьютер, тренировка, сравнение ходов, сохранение, Screen Capture, OpenCV/ONNX и ручной редактор.

Расширение: шахматы на Chess.com/Lichess и русские шашки 8×8 на Lidraughts. Автоматически читает доску и отслеживает легальные ходы. Рамки и стрелка находятся поверх исходной доски, следуют за переворотом и прокруткой и пропускают клики. Моя сторона: Авто/Белые/Чёрные; цвет сохраняется отдельно для сайта. Авто запоминает сторону снизу при подключении, переворот её не меняет. На ходу соперника рамки, стрелка и рекомендация скрываются; поиск останавливается, отслеживание продолжается.

Русские шашки: обязательный бой в обе стороны, выбор любой полной серии взятий, дальнобойные дамки, превращение во время боя, снятие побитых шашек после полного хода. Отслеживаются полные и промежуточные прыжки, два быстрых полухода, известная история и ничейные счётчики. Подсказка показывает весь маршрут и оставшуюся часть боя. Собственный локальный alpha-beta поиск работает в отдельном Worker с бюджетом 1,5 секунды и фактической глубиной. Это учебный эвристический движок без таблиц окончаний и без заявленного рейтинга. Stockfish используется только для шахмат.

## Ограничения

Расширение поддерживает указанные три сайта; произвольные сайты и canvas-доски не заявлены. Русский режим не подходит для международных 10×10, бразильских или английских шашек. Неполная история при подключении посреди партии может потребовать полного FEN один раз. Неизвестную историю ничейных счётчиков нельзя восстановить по расстановке. Изменение разметки сайтов может потребовать обновления адаптера.

ONNX-модель веб-тренажёра поддерживает его набор фигур и три темы, а не любые скриншоты. Малые изображения требуют коррекции. Захват экрана через настоящий системный диалог зависит от разрешения пользователя. Arch/KDE отдельно не запускался; Linux CI использует Ubuntu/Chromium. Готовое расширение для обработки доски использует DOM, поэтому ему не нужна ONNX-модель.

## Обновление и запуск

После обновления файлов нажмите Обновить на карточке расширения в chrome://extensions и перезагрузите страницу сайта. Русские шашки: https://lidraughts.org/analysis/russian. При необходимости выберите свой цвет в Моя сторона.

Разработка: npm install, npm run dev. Обе сборки: npm run build. Только расширение: npm run build:extension. Проверки: npm test, npm run test:e2e, npm run test:extension. Публикация Pages выключена по умолчанию; инструкция и ENABLE_PAGES описаны в README. Полная инструкция расширения — INSTALL_EXTENSION.md.
