# Результат разработки

## Реализовано

Архив распакован, исходная версия сохранена отдельно. Приложение переработано в модульную структуру: React/TypeScript/Vite, Tailwind, chess.js, react-chessboard, Stockfish 17.1 Lite single-thread WASM, OpenCV.js и ONNX Runtime Web. Вычисления локальные, сервер и аккаунт не нужны.

Работают анализ depth 15 / MultiPV 1, отмена устаревших поисков, остановка, оценки и мат, PV/SAN, зелёная стрелка и шкала, три темы, история, FEN/PGN, отмена/повтор, выбор превращения, компьютер со сложностью, тренировка и сохранение попыток, горячие клавиши, localStorage, захват экрана с проверкой изменений и обработкой закрытия источника. Объяснения используют фактические оценки до/после хода и шахматные правила.

Добавлены поиск доски OpenCV, локальная ONNX-модель по эталонам фигур, редактор всех клеток и явный ввод неизвестных полей FEN. Распознавание не имитируется при отказе модели. Для применения позиции необходимо проверить фигуры, ориентацию, очередь хода, рокировку и en passant.

## Проверки

- `npm run build`: успешная сборка и проверка TypeScript.
- `npm test`: 11 unit-тестов, все прошли.
- Браузерные проверки Chrome: 5 сценариев приложения — настоящий WASM Stockfish, глубина 15, ход/история/отмена/повтор, мат, стрелка и её переворот, FEN/PGN, сохранение, компьютер, тренировка, отказ в захвате, тестовый видеопоток и закрытие источника.
- Браузерные проверки распознавания: 6 сценариев — три темы, обе ориентации, поиск доски внутри изображения с полями, неизвестные клетки на маленьком скриншоте, честная ошибка отсутствующей модели. Используются реальные OpenCV и ONNX Runtime.
- Вёрстка проверена автоматически на ширинах 320, 390, 768 и 1440 пикселей; горизонтального переполнения нет. Скриншоты осмотрены.

## Ограничения

- Встроенная модель предназначена для стандартных SVG-фигур react-chessboard и трёх тем тренажёра. Универсальное распознавание любых сайтов, наборов фигур и фотографий не готово: нужна другая обученная совместимая модель. Можно загрузить её вручную. Скриншоты должны быть без стрелок/подсветок.
- На доске шириной 331 пиксель некоторые фигуры отклонены как неизвестные; распознанные клетки проверенного изображения верны. Рекомендуется доска от 512 пикселей и ручная проверка.
- Перспективные фотографии не поддерживаются. Автопоиск рассчитан на квадратную доску на прямом скриншоте; есть ручной кроп.
- Разбор ходов — объяснимые факты и сравнение поиска, не полноценный стратегический комментарий уровня тренера. Пороги качества эвристические, глубина ограничена.
- Системный диалог выбора экрана и реальный отзыв разрешения пользователем не автоматизированы. Проверены отказ API и жизненный цикл тестового видеопотока; настоящий захват зависит от разрешения пользователя.
- Arch Linux/KDE не запускался в этой Windows-среде. Требуются рабочие браузерный Screen Capture API, PipeWire и xdg-desktop-portal-kde.
- Подтверждение FEN после снимка обязательно: автоматическая замена позиции без подтверждения неизвестных параметров не выполняется.
- Скрытые подсказки в рейтинговых онлайн-матчах отсутствуют.

## Запуск и публикация

Готовая локальная сборка запускается файлом `Start Chess Vision.cmd`; требуется Node.js (на этом компьютере предусмотрен резервный путь к установленному runtime Codex). Для разработки: `npm install`, `npm run dev`. Сборка: `npm run build`.

Публикация подготовлена, но выключена по умолчанию. GitHub служит резервной копией исходников. Для Pages выберите GitHub Actions в Settings → Pages, задайте Actions variable `ENABLE_PAGES=true`, запустите workflow. Полная инструкция, ограничения приватного репозитория и лицензии — в README.
