♞ Chess Vision 1.2

Шахматы: Chess.com и Lichess. Русские шашки 8×8: доска анализа Lidraughts.

В «Моя сторона» выберите свой цвет. «Авто» запоминает цвет снизу при подключении. Переворот доски не меняет вашу сторону.

Жёлтая рамка — откуда, зелёная — куда. На ходу соперника рамки, стрелка и рекомендация скрыты.

Только король: рядом с глубиной в «Ходы Stockfish» выберите «Только король». Движок сравнит легальные ходы короля, включая доступную рокировку. Если их нет, вы увидите сообщение без рамок и оценки. Для обычного анализа выберите «Все фигуры». В шашках эта настройка отключена.

Слепая доска Chess.com: включите одноимённый флажок для скрытых фигур. Расширение читает их данные, не делая фигуры видимыми. Без элементов фигур нужны полный FEN со страницы или полная история с последовательными номерами полуходов. Неполная история не используется для угадывания позиции. Отдельный интерфейс Variants / Blindfold без доступных данных доски не проверен.

В шашках показывается весь маршрут взятия, включая промежуточные клетки. После первого прыжка подсказка указывает оставшуюся часть боя.

Stockfish анализирует шахматы. Русские шашки рассчитывает отдельный локальный движок с лимитом поиска 1,5 секунды. Глубина и оценка показываются по фактическому расчёту.

Начните с начала партии. Если история недоступна, вставьте FEN с сайта один раз. После обновления расширения перезагрузите вкладку сайта.
