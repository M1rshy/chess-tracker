# Подсказки прямо на доске сайта

## Версия 1.2: выбор фигуры и скрытые фигуры Chess.com

Рядом с глубиной анализа есть отдельный список **Ходы Stockfish**. Выберите **Только король**, чтобы сравнивались только легальные ходы короля (включая разрешённую рокировку). Если таких ходов нет, расширение скрывает рамки и оценку и сообщает об этом. Вернуться к обычному анализу можно через **Все фигуры**. Выбор сохраняется; шашки используют свой движок без этого ограничения. Оценка ограниченного поиска относится к лучшему ходу короля, а не к лучшему ходу среди всех фигур.

Флажок **Слепая доска Chess.com** позволяет читать данные скрытых фигур без изменения их видимости. Если сайт не создаёт элементы фигур, используются полный FEN со страницы или легальная история с последовательными номерами полуходов, начиная с первого. Если доступен только последний ход соперника, позиция не угадывается: подсказка отключается. Отдельный интерфейс **Variants / Blindfold** без доступных данных доски не проверен.

После установки обновления 1.2 нажмите **Обновить** на карточке расширения в `chrome://extensions`, затем перезагрузите вкладку с доской. Новые настройки находятся в панели на странице рядом с глубиной Stockfish.

Готовое расширение Chrome/Chromium/Edge определяет шахматную доску Chess.com/Lichess или русские шашки 8×8 на Lidraughts и рисует рамки поверх неё. Жёлтая рамка показывает, какую фигуру двигать, зелёная — куда. Стрелка соединяет клетки. Клики проходят сквозь подсказку к исходной доске.

## Установка в Chrome

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** в правом верхнем углу.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку **Chess Vision Extension** внутри основной папки проекта на рабочем столе. В ней должен лежать `manifest.json`.
5. Перезагрузите вкладку Chess.com, Lichess или Lidraughts.

Рядом лежит `Install Browser Extension.cmd`: он открывает страницу расширений и нужную папку в Проводнике. Загрузка папки и выдача браузерного разрешения выполняются самим пользователем. Для Edge используйте `edge://extensions`; в Chromium также `chrome://extensions`.

Если вы собираете из исходников: `npm install`, затем `npm run build:extension`. Для загрузки выберите созданную папку `extension-build`. ZIP сначала нужно распаковать; выбирать сам ZIP в диалоге расширений нельзя.

## Использование

На странице анализа Chess.com закройте приветственное окно, если оно появилось, и выберите New Analysis. Откройте доску. Панель **Chess Vision** появится автоматически. Начните с начальной расстановки — очередь хода, рокировка, превращения и взятие на проходе дальше ведутся шахматными правилами. Размещение фигур считывается со страницы, поэтому цвет доски и рисунок фигур не требуют ONNX-модели. Предыдущий веб-тренажёр с распознаванием скриншотов также сохранён.

Stockfish 17.1 WASM запускается локально, по умолчанию глубина 15. Предварительная подсказка уточняется по мере расчёта; панель показывает достигнутую глубину и реальную оценку для белых. Пауза скрывает рамки и останавливает движок. Кнопка `↻` перечитывает доску. Панель можно свернуть кнопкой `−`. Рамки следуют за прокруткой, размером и переворотом доски. Расширение само ходов не делает.

При подключении посреди партии расширение использует полный FEN или доступную последовательность SAN-ходов на странице. Если сайт скрывает/виртуализирует часть истории, достоверно восстановить невидимые права рокировки невозможно. В таком случае откройте **Позиция FEN / повторная синхронизация**, вставьте полный FEN один раз и нажмите **OK**. Дальнейшие изменения будут отслеживаться автоматически. FEN должен совпадать с расстановкой на странице.

Обычные ходы, два быстрых полухода между проверками, рокировка, en passant и превращения проверяются chess.js. Непонятное изменение доски останавливает выдачу подсказки и требует синхронизации. Анимация и перетаскивание скрывают старые рамки. Поддерживаются стандартные шахматы и обычная 2D-доска; произвольные сайты и варианты вроде Chess960 не заявлены. При изменении внутренней разметки сайтов адаптеры могут потребовать обновления.

## Данные и разрешения

Доступ ограничен `*.chess.com` и `lichess.org`. Расширение читает элементы шахматной доски и список ходов на этих страницах. Расположение фигур и вычисления не отправляются внешнему серверу. Разрешения `storage` и `offscreen` нужны для настроек и фонового документа с локальным Worker. Основной веб-тренажёр или локальный HTTP-сервер для расширения запускать не требуется.

Лицензия проекта и Stockfish: GPLv3; chess.js: BSD-2-Clause. Уведомления и ссылки на соответствующий исходный код включены в папку расширения. Используйте расширение для тренировок и анализа разрешённых позиций.

## Проверка и обновление

`npm test` проверяет шахматные правила и отслеживание. `npm run test:extension` запускает расширение с настоящим Stockfish в тестовом Chromium. Установите тестовый браузер командой `npx playwright install chromium`. Для проверки установленным Edge на Windows: `$env:CVT_EXTENSION_BROWSER='msedge'; npm run test:extension`. Это отдельный тестовый профиль, без входа в аккаунт и без онлайн-партий.

После замены файлов расширения нажмите **Обновить** на его карточке в `chrome://extensions`, затем обновите страницу с доской.


## Версия 1.1: своя сторона и русские шашки

В панели добавлен выбор **Моя сторона**: Белые, Чёрные или Авто. Авто запоминает цвет фигур снизу при подключении к доске; последующий переворот доски цвет игрока не меняет. При новой партии проверьте выбранный цвет. Настройка сохраняется отдельно для каждого сайта. На ходу соперника скрываются рамки, стрелка и текст рекомендации, а расчёт останавливается. Отслеживание ходов продолжается, чтобы подсказка вернулась на вашем ходу.

Русские шашки доступны на https://lidraughts.org/analysis/russian. Игра определяется автоматически; при неоднозначной странице выберите **Русские шашки 8×8** в поле Игра. Международные 10×10, бразильские и английские шашки этим режимом не поддерживаются. Поддержка произвольных шашечных сайтов не заявлена.

Правила реализованы по официальным правилам IDF/FMJD-64: https://fmjd64.org/rules-of-the-game/ и описанию русского варианта Lidraughts: https://lidraughts.org/variant/russian. Обязательный бой, бой простых шашек назад, свободный выбор полной серии без требования максимального числа взятий, дальнобойные дамки, превращение во время боя, запрет повторного взятия и прохода через уже побитую шашку проверяются локально. Во время серии показываются промежуточные клетки и оставшиеся прыжки. Отслеживаются повторения и счётчики ничейных окончаний, если история наблюдалась; неизвестную прошлую историю по одному FEN восстановить нельзя, результат партии на сайте остаётся определяющим.

Для шашек работает собственный поиск alpha-beta с углублением и продолжением обязательных взятий на границе поиска. Бюджет 1,5 секунды на позицию; в панели показывается фактически завершённая глубина. Эвристика учитывает материал, дамок и расположение. Это учебный движок без таблиц окончаний и без заявленного рейтинга; Stockfish для шашек не используется.

Готовое обновление лежит в той же папке **Chess Vision Extension**. Откройте chrome://extensions, нажмите **Обновить** на карточке Chess Vision, затем обновите вкладку с доской.
