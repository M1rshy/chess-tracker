# Chess Vision Trainer

Локальный шахматный тренажёр на React + TypeScript + Vite. Реальные шахматные правила, Stockfish 17.1 Lite WASM в Web Worker, обучение, захват экрана и распознавание поддерживаемых скриншотов. Серверная часть, регистрация и платные API не требуются.

## Быстрый запуск

Установите Node.js 22 LTS или новее. Работает в Chrome/Chromium на Windows и Linux.

```sh
npm install
npm run dev
```

Откройте адрес из терминала, обычно http://127.0.0.1:5173. При установке автоматически копируются локальные JS/WASM-файлы Stockfish, OpenCV и ONNX Runtime. CDN не используются.

```sh
npm test
npm run build
npm run preview
```

`npm run build` проверяет TypeScript, копирует вычислительные библиотеки и собирает приложение в `dist/`.

На подготовленной локальной копии с готовой папкой `dist` можно дважды нажать **Start Chess Vision.cmd**. Скрипт запускает локальный HTTP-сервер и открывает http://127.0.0.1:4173. Он использует установленный Node.js, а на этом компьютере также умеет находить поставляемый с Codex Node.js. В Linux: `sh start-linux.sh`. Для запуска готовой сборки нужен только Node.js; установка npm-зависимостей не обязательна. Оставляйте терминал сервера открытым. После изменения исходников пересоберите `dist`.

Не открывайте index.html двойным щелчком через file://: браузер блокирует Workers и WASM. Захват работает только через HTTPS или localhost.

## Возможности

- chess.js проверяет легальность ходов, рокировку, взятие на проходе, превращение, мат и ничьи. Доступны перетаскивание, клики по клеткам и ввод UCI. При превращении можно выбрать любую фигуру.
- История партии сохраняется полностью. Есть отмена/повтор, новая партия, переворот доски, импорт и экспорт FEN/PGN. Комментарии PGN загружаются chess.js; приложения с расширенной PGN-разметкой и боковыми вариантами не являются редактором вариантов этого тренажёра.
- Stockfish по умолчанию анализирует на глубине 15, MultiPV=1. Показываются реальная оценка для белых, мат, SAN/UCI лучшего хода, основной вариант, достигнутая глубина, состояние движка. Автоанализ после каждого хода, остановка и перезапуск. Отменённый поиск дожидается bestmove, и устаревшие ответы не попадают в новую позицию.
- Зелёная стрелка, подсветка начальной/конечной клеток, вертикальная шкала оценки. Переворот меняет доску, стрелку и ориентацию шкалы. Стрелки отключаются в настройках.
- Игра против Stockfish: выбор стороны и Skill Level 0/3/5/10/15/20, ограничение глубины ответа. Это уровни движка, а не обещанные значения Elo.
- Тренировка поиска лучшего хода в текущей позиции и несколько встроенных упражнений. Подсказки скрыты до попытки или явного раскрытия решения. История попыток сохраняется локально и экспортируется в JSON.
- Учебный разбор сравнивает позиции до и после хода реальным Stockfish на одинаковой глубине. Показывает потерю оценки, предпочтительное продолжение и факты правил: взятие, шах, мат, превращение, рокировку, атаки фигур. Пороги потери оценки: 0.2/0.5/1.0/2.0 пешки. Это прозрачная эвристика классификации, не универсальная оценка качества и не языковая AI-модель.
- Три темы доски, адаптивный интерфейс, сохранение настроек и текущей партии в localStorage. При отказе хранилища показывается ошибка; экспорт PGN остаётся доступен.

Горячие клавиши: **←** отменить, **→** повторить, **F** перевернуть, **Esc** закрыть выбор/настройки. В полях ввода они не перехватываются. В режиме компьютера отмена/повтор возвращают пару ходов, чтобы компьютер не делал отменённый ответ сразу снова.

## Скриншоты, OpenCV и ONNX

1. Откройте вкладку **Захват**, загрузите изображение или нажмите **Начать захват** и выберите окно/вкладку в системном диалоге браузера.
2. Изображение проверяется каждые 2 секунды. Повторная обработка отключена по умолчанию. Для неё включите флажок распознавания изменений. Проверяется область доски; мелкий шум игнорируется, перед распознаванием требуется два стабильных кадра.
3. OpenCV ищет квадратные контуры и проверяет чередующуюся сетку 8×8. Если границы не найдены, включите ручной квадратный кроп и задайте X/Y/ширину в процентах. Поддерживаются прямые скриншоты, не перспективные фотографии.
4. ONNX Runtime в отдельном Worker классифицирует 64 клетки. **Встроенная модель работает только с фигурами react-chessboard 4.7.3 и тремя темами этого тренажёра.** Это классификатор по эталонам, не универсальная нейросеть для любых сайтов. Снимайте доску без стрелок, подсветок и перекрывающих окон. Для маленьких снимков часть клеток может потребовать ручной коррекции; предпочтительна доска от 512 пикселей. Неизвестные клетки отмечаются `?`. Даже уверенные результаты нужно проверить.
5. Отредактируйте фигуры палитрой. Ориентация по расположению королей — лишь предположение; явно укажите, кто снизу.
6. Явно укажите очередь хода, права рокировки и поле en passant (`-`, если отсутствует). Эти параметры не угадываются из изображения. Счётчики полуходов/ходов можно изменить вручную.
7. Нажмите **Проверить FEN и анализировать**. Только после проверки позиция попадёт на доску и в Stockfish. Кадры захвата автоматически не заменяют анализируемую позицию без подтверждения этих данных.

Для другого набора фигур загрузите совместимую ONNX-модель: один вход RGB float32 `[1,3,64,64]` в диапазоне 0…1, один выход логитов `[1,13]`, классы `. P N B R Q K p n b r q k`. Поддерживается обычный `.onnx` и gzip. Модель проверяется пробным инференсом. При недоступной/неработающей модели распознавание не имитируется: показывается причина, неизвестные клетки требуют ручного заполнения. Подробнее в `public/models/README.md`; скрипты воспроизведения включены.

Обработка изображений и вывод модели выполняются локально. Отмена разрешения, закрытие источника или кнопка остановки завершают захват и таймеры. Не выбирайте окно, содержащее саму трансляцию: возникает повторяющееся изображение. На Arch Linux/KDE выбор источника зависит от рабочего xdg-desktop-portal-kde/PipeWire и поддержки браузера; эти системные компоненты приложение не устанавливает.

## Тестирование

```sh
npm test
npm run test:e2e
```

Playwright использует установленный Google Chrome, в том числе предустановленный Chrome в Linux-образе GitHub Actions. Для Chromium/Arch задайте `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`; другой канал выбирается через `PLAYWRIGHT_CHANNEL`. Тесты проверяют настоящую WASM-сборку, мат, стрелку/переворот, ходы, историю, FEN/PGN, сохранение, ответ компьютера, тренировку, отказ в захвате, распознавание скриншота реальным OpenCV/ONNX и честную ошибку при отсутствии модели. Размеры интерфейса: 320, 390, 768, 1440. Скриншоты/трассы сохраняются в `test-results/`.

Настоящий системный диалог выбора экрана и отзыв разрешения пользователем требуют ручной проверки. Linux/KDE не проверен на этом Windows-компьютере. Встроенная модель не проверена на произвольных наборах фигур и фотографиях.

## GitHub как резервная копия и GitHub Pages

Локальная папка на компьютере — основной проект. GitHub хранит исходники, модель и lockfile; node_modules, dist и временные файлы не коммитятся. Делайте резервную копию изменённых исходников обычными коммитами. PGN/настройки в браузере не входят в Git: экспортируйте нужные партии отдельно.

Workflow `.github/workflows/pages.yml` запускает npm ci, unit-тесты, браузерные проверки и сборку. Публикация выключена по умолчанию, чтобы GitHub оставался резервной копией.

Чтобы включить Pages:

1. В репозитории откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. В **Settings → Secrets and variables → Actions → Variables** создайте `ENABLE_PAGES` со значением `true`.
3. Запустите workflow через **Actions → Verify and publish Chess Vision Trainer → Run workflow**, либо отправьте коммит в main.
4. После успешного deploy адрес появится в workflow/Pages. Для `M1rshy/chess-tracker` обычно используется https://m1rshy.github.io/chess-tracker/.

Workflow выставляет Vite base автоматически по имени репозитория. Локальная сборка использует относительный `./`; свой путь задаётся `VITE_BASE_PATH`. Например PowerShell: `$env:VITE_BASE_PATH='/chess-tracker/'; npm run build`. Для локального запуска снова удалите эту переменную и пересоберите.

Репозиторий сейчас приватный. Если Pages недоступен на вашем тарифе для приватного репозитория, оставьте его резервной копией или отдельно примите решение о публичной публикации. Приложение не меняет видимость репозитория.

## Структура

- `src/App.tsx` — партия, режимы, обучение и интерфейс.
- `src/engine.ts` — очередь UCI и жизненный цикл Stockfish Worker.
- `src/chess.ts` — проверка FEN, объяснения и оценка потерь.
- `src/VisionPanel.tsx`, `src/vision.ts`, `public/vision-worker.js` — захват, редактор и обработка изображения.
- `src/storage.ts` — настройки, localStorage и экспорт.
- `public/models/` — локальная модель и её область применения.
- `scripts/copy-assets.mjs` — автономные вычислительные библиотеки при установке/сборке.
- `scripts/build-model.py`, `scripts/generate-templates.mjs` — воспроизведение модели.
- `src/*.test.ts`, `e2e/` — тесты правил, движка, UI и распознавания.
