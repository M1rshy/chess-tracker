# Chess Vision Trainer

Локальный тренажёр для анализа шахматных позиций и поиска лучших ходов. Веб-приложение объединяет интерактивную доску, Stockfish и распознавание скриншотов. Отдельное браузерное расширение добавляет подсказки поверх досок Chess.com, Lichess и Lidraughts.

Вычисления выполняются на устройстве пользователя. Для анализа не нужны аккаунт, платные API или серверная часть. Проект предназначен для обучения, игры против компьютера и анализа позиций, где разрешена помощь движка.

## Возможности

### Веб-тренажёр

- Интерактивная шахматная доска: клики, перетаскивание, ввод ходов UCI и выбор фигуры при превращении.
- Stockfish 17.1 Lite WebAssembly в Web Worker: автоматический анализ после хода, глубина 15 и MultiPV = 1 по умолчанию.
- Лучший ход, основной вариант, достигнутая глубина, состояние движка, числовая и матовая оценки. Оценка приведена к стороне белых.
- Зелёная стрелка и подсветка клеток, вертикальная шкала оценки, переворот доски и отключение подсказок.
- Игра против Stockfish с выбором стороны и сложности. Уровни Skill Level не приравниваются к Elo.
- Тренировка поиска лучшего хода, история попыток и экспорт результатов в JSON.
- Разбор ходов по сравнению оценок Stockfish до и после хода на одинаковой глубине, с фактами о взятиях, шахах и атаках фигур.
- Импорт и экспорт FEN/PGN, история партии, отмена и повтор ходов.
- Захват окна или вкладки, поиск границ доски через OpenCV.js, распознавание фигур через ONNX Runtime Web и ручной редактор позиции.
- Тёмный адаптивный интерфейс, три темы доски и сохранение партии и настроек в localStorage.

### Браузерное расширение

| Сайт | Поддержка |
| --- | --- |
| Chess.com | Шахматы, чтение доски и локальный анализ Stockfish |
| Lichess | Шахматы, чтение доски и локальный анализ Stockfish |
| Lidraughts | Русские шашки 8×8, отдельный локальный движок |

Расширение читает элементы доски на странице и отслеживает легальные ходы. Жёлтая рамка отмечает исходную клетку, зелёная — конечную; стрелка показывает направление. Рамки следуют за доской при прокрутке и перевороте, а клики проходят к самой доске.

В настройке **«Моя сторона»** можно выбрать белых, чёрных или автоматическое определение. В режиме «Авто» запоминается цвет снизу при подключении; последующий переворот доски не меняет выбранную сторону. На ходу соперника рамки, стрелка и рекомендация скрываются. Отслеживание позиции продолжается.

В русских шашках отображается полный маршрут серии взятий и оставшаяся часть боя после промежуточного прыжка. Движок учитывает обязательное взятие, бой назад, летающих дамок и превращение во время боя. Поиск использует alpha-beta с последовательным углублением и бюджетом 1,5 секунды; интерфейс показывает фактически завершённую глубину. Это отдельная реализация движка шашек, без заявленного рейтинга и эндшпильных баз.

Расширение не выполняет ходы автоматически. Поддержка других сайтов и вариантов шашек пока не реализована.

## Быстрый запуск

Требуются **Node.js 22 или новее**, npm и современный Chrome/Chromium. Для расширения нужен браузер на Chromium версии 116 или новее; также поддерживается Edge.

```sh
git clone https://github.com/M1rshy/chess-tracker.git
cd chess-tracker
npm ci
npm run dev
```

Откройте адрес из терминала, обычно [http://127.0.0.1:5173](http://127.0.0.1:5173). При установке зависимости Stockfish, OpenCV и ONNX Runtime копируются в локальные ресурсы приложения. Во время анализа библиотеки не загружаются с CDN.

Для проверки готовой сборки:

```sh
npm run build
npm run preview
```

Веб-приложение собирается в `dist/`, расширение — в `extension-build/`. Готовое веб-приложение можно также запустить командой `node scripts/serve.mjs`: сервер откроется по адресу [http://127.0.0.1:4173](http://127.0.0.1:4173). В репозитории есть скрипты запуска `Start Chess Vision.cmd` для Windows и `start-linux.sh` для Linux.

Открывайте приложение через HTTP/HTTPS, а не двойным щелчком по `index.html`: Workers и WebAssembly требуют корректной загрузки ресурсов.

## Установка расширения

1. Установите зависимости и соберите расширение:

   ```sh
   npm ci
   npm run build:extension
   ```

2. Откройте `chrome://extensions` или `edge://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку `extension-build` в клонированном проекте. В ней должен находиться `manifest.json`.
5. Откройте или перезагрузите поддерживаемую доску, например [анализ Lichess](https://lichess.org/analysis) или [русские шашки на Lidraughts](https://lidraughts.org/analysis/russian).
6. Выберите свою сторону в панели расширения.

После обновления исходников повторите сборку, обновите расширение на странице управления расширениями и перезагрузите вкладку с доской. Скрипт `Install Browser Extension.cmd` помогает открыть страницу установки, но выбор папки выполняется вручную.

Готовую сборку также можно скачать из **Actions → успешный запуск workflow → Artifacts → Chess-Vision-Extension**. Распакуйте архив и загрузите папку с `manifest.json` тем же способом.

**Синхронизация позиции.** Надёжнее подключаться с начала партии. Если расширение открыто посреди игры и сайт не предоставляет достаточную историю, потребуется один раз вставить полный FEN с сайта. Права рокировки и другие скрытые параметры нельзя достоверно восстановить только по расположению фигур.

**Разрешения.** Расширение использует `storage`, `offscreen` и доступ к страницам Chess.com, Lichess и Lidraughts. Анализ выполняется локально; для шахмат загружается упакованный вместе с расширением Stockfish.

## Захват экрана и распознавание

1. Откройте раздел **«Захват»** и загрузите изображение либо нажмите **«Начать захват»**.
2. В системном диалоге браузера выберите окно или вкладку.
3. Приложение проверяет изображение каждые 2 секунды. Для повторного распознавания включите обработку изменений: мелкий шум игнорируется, распознавание начинается после стабилизации кадра.
4. OpenCV ищет квадратную доску 8×8. Если границы не найдены, задайте область вручную.
5. Проверьте распознанные фигуры и исправьте их палитрой.
6. Укажите ориентацию, очередь хода, права рокировки и поле взятия на проходе (`-`, если его нет). При необходимости поправьте счётчики ходов.
7. Нажмите **«Проверить FEN и анализировать»**, чтобы передать проверенную позицию Stockfish.

**Область применения модели:** встроенный ONNX-классификатор рассчитан на прямые скриншоты фигур `react-chessboard 4.7.3` с тремя темами этого приложения. Универсальное распознавание произвольных сайтов, наборов фигур и фотографий не поддерживается. Для поддерживаемых сайтов используйте расширение: оно читает доску напрямую.

Неизвестные клетки отмечаются `?`; при отсутствии или ошибке модели выводится сообщение об ошибке. Изображение не содержит всей информации FEN, поэтому подтверждение скрытых параметров остаётся обязательным. Подробнее о формате пользовательской модели и воспроизведении встроенной: [public/models/README.md](public/models/README.md).

Захват требует HTTPS или localhost и разрешения пользователя. Кнопка остановки, закрытие источника и отзыв разрешения завершают трансляцию. На Linux/KDE выбор источника зависит от настройки PipeWire и `xdg-desktop-portal-kde`.

## Управление и данные

| Клавиша | Действие в веб-тренажёре |
| --- | --- |
| `←` | Отменить ход |
| `→` | Повторить ход |
| `F` | Перевернуть доску |
| `Esc` | Закрыть выбор или настройки |

Горячие клавиши не перехватываются в полях ввода. В режиме игры против компьютера отмена и повтор возвращают пару ходов.

Партия, настройки и тренировки хранятся в браузере. Данные разных браузеров и адресов приложения не синхронизируются. Для переноса или резервного копирования экспортируйте PGN и историю тренировок.

### Тестирование

```sh
npm run check
npm test
npm run test:e2e
npx playwright install chromium
npm run test:extension
npm run build
```

Веб-тесты по умолчанию используют установленный Google Chrome. Для другого браузера можно задать `PLAYWRIGHT_CHANNEL` или путь `CHROMIUM_PATH`. Например, в Linux:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

Тесты расширения используют установленный через Playwright Chromium. Покрыты правила шахмат и русских шашек, настоящий Stockfish WASM, матовые оценки, стрелки и переворот доски, FEN/PGN, сохранение, игра против компьютера, тренировки, OpenCV/ONNX и ошибки модели. Браузерные проверки также проверяют скрытие подсказок на ходу соперника, серии взятий и интерфейс на разных размерах экрана.

Тесты жизненного цикла захвата используют подменённый медиапоток. Системный диалог выбора экрана и взаимодействие с порталом KDE требуют ручной проверки.

## Публикация на GitHub Pages

Workflow [pages.yml](.github/workflows/pages.yml) запускает тесты и сборку при push в `main`, pull request и ручном запуске. Он сохраняет отчёты проверок, веб-сборку и расширение как артефакты.

Для включения публикации:

1. Откройте **Settings → Pages** и выберите **Source: GitHub Actions**.
2. В **Settings → Secrets and variables → Actions → Variables** создайте переменную `ENABLE_PAGES` со значением `true`.
3. Запустите **Actions → Verify and publish Chess Vision Trainer → Run workflow** либо отправьте коммит в `main`.
4. После успешного задания `deploy` адрес сайта появится в Pages и результатах workflow.

Для этого репозитория ожидаемый адрес — [https://m1rshy.github.io/chess-tracker/](https://m1rshy.github.io/chess-tracker/); он станет доступен после включения публикации и успешного развёртывания.

Workflow задаёт `VITE_BASE_PATH` по имени репозитория. Локальная сборка по умолчанию использует относительный путь `./`. Для другого адреса задайте переменную перед сборкой, например в PowerShell:

```powershell
$env:VITE_BASE_PATH = '/chess-tracker/'
npm run build
Remove-Item Env:VITE_BASE_PATH
```

GitHub Pages размещает веб-тренажёр. Браузерное расширение устанавливается отдельно.

## Технологии и структура

React · TypeScript · Vite · Tailwind CSS · chess.js · react-chessboard · Stockfish WebAssembly · Web Workers · OpenCV.js · ONNX Runtime Web · Vitest · Playwright.

```text
src/                   Веб-интерфейс, управление партией, движком и хранением
extension/             Чтение досок сайтов, рамки, отслеживание и движок шашек
public/models/         Локальная модель распознавания и документация
public/vision-worker.js Обработка изображений в Worker
scripts/               Сборка, копирование ресурсов, сервер и инструменты модели
e2e/                   Браузерные тесты веб-приложения
.github/workflows/     Автоматические проверки и публикация
```

Ресурсы движка и библиотек копируются из npm-зависимостей при установке и сборке. Папки `node_modules/`, `dist/` и `extension-build/` не входят в исходники репозитория.

## Ограничения

- Чтение сайтов зависит от их разметки. После изменения интерфейса сайта адаптеру может потребоваться обновление.
- Поддерживаются обычные шахматы и русские шашки 8×8; другие варианты не заявлены.
- Учебные объяснения основаны на оценках движка и шахматных правилах. Полноценного языкового тренера в проекте нет.
- Для корректного учёта истории, повторений и счётчиков нужна доступная история партии. Если она неполная, результат партии на сайте остаётся определяющим.
- Модель распознавания имеет ограниченный набор поддерживаемых фигур; ошибки исправляются в редакторе позиции.
